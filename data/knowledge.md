# LanShare 项目知识库

## 项目目的

LanShare 是一个用于局域网设备互传信息的个人小工具。它主要解决手机与电脑之间传输少量文件或文字时，使用微信等外部应用步骤较多、受外部网络状态影响的问题。只要设备连接到同一个局域网，就可以通过浏览器访问服务端提供的页面，不需要安装额外客户端。

## 访问方式

LanShare 由一台电脑运行 Spring Boot 服务，其他设备通过“服务端局域网 IP 地址加 8080 端口”访问，例如 `http://192.168.1.10:8080`。页面还可以显示访问二维码，手机扫描后能够直接打开对应网址。二维码本质上只是对访问地址进行编码，不依赖第三方二维码服务。

## 文件共享

用户可以通过浏览器上传文件，服务端提供文件列表、下载和手动删除功能。单个文件大小上限为 100 MB，空文件会被拒绝。同名文件不会相互覆盖：服务端为每次上传生成唯一标识，因此两个同名文件可以分别保存。文件持久化存放在服务端本地的 `uploads` 目录中，服务重启后仍然存在，只有用户主动删除时才会消失。

## 文字共享

LanShare 支持在局域网内添加、查看、复制和删除共享文字。文字同样持久化保存在服务端本地，服务重启后不会丢失。连接到服务端的设备会看到相同的文字列表；一台设备增加或删除内容后，其他设备随后也能看到变化。数据保留由使用者决定，程序不会自动清理文字或文件。

## 自动刷新

文字列表使用 JavaScript 轮询刷新。轮询不是刷新整个网页，而是定期发送异步请求，只更新文字列表区域。因此用户正在输入长文本或选择上传文件时，页面表单不会被清空，文件上传请求也不会因为文字列表刷新而中断。代码使用 `textRefreshInProgress` 一类的状态标记，避免上一次刷新尚未完成时再次发起重叠请求。

## 技术结构

项目后端使用 Spring Boot，前端使用内置的 HTML、CSS 和 JavaScript，没有单独创建前端工程，也没有使用数据库。后端主要分为 Controller 和 Service：Controller 接收浏览器请求并调用 Service，Service 负责文件、文字和本地存储等具体逻辑。数据保存在运行服务的电脑上，其他设备只是通过浏览器访问和操作这些数据。

## 安全与性能限制

当前版本没有账号、访问码和权限控制，同一局域网内能够访问服务地址的设备都可能查看或修改共享内容，因此只适合可信局域网，不应直接暴露到公网。在性能方面，项目限制了单文件大小，但没有限制上传速率、文件总数量或存储空间，也不支持断点续传、分片上传和自动清理。它定位为个人和小规模可信网络中的实用工具，而不是面向大量用户的生产级文件服务。
